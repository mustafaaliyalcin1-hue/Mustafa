# Higgsfield — Editorial Motion Graphics (hazır, ETKİN DEĞİL)

Kaynak: higgsfield.ai/skills/editorial-motion-graphics (bu ortamdan erişilemedi; sayfanın GitHub'daki arşiv kopyasından okundu).

**Ne:** Konudan "editorial motion graphics" tarzında yüzsüz (faceless) açıklama videosu: senaryo, sahneler,
seslendirme (İngilizce örneklerde), altyazı, montaj. Üretim **Higgsfield bulutunda** yapılır (ör. Google Omni ile video).
Yerel bir kod/skill değildir; Higgsfield MCP bağlantısı üzerinden çalışır.

**Kurulum yolu (resmi):**
1. Bağlantı adresi: `https://mcp.higgsfield.ai/mcp`
2. claude.ai veya Claude masaüstü → **Customize → Connectors** → "Higgsfield" adıyla bu adresi ekle.
   (Claude Code CLI karşılığı: `claude mcp add --transport http higgsfield https://mcp.higgsfield.ai/mcp`)
3. **Higgsfield hesabıyla giriş yap** (OAuth). Sonra: "Create a faceless explainer video in an editorial motion graphics
   style about …"

**Senden gerekenler:** Higgsfield hesabı + giriş (OAuth; şifre buraya yazılmaz) ve **kredi/ücretli plan** — her video
üretimi kredi harcar. Bu ortamda ayrıca `mcp.higgsfield.ai` ağ izni gerekir (şu an engelli).

**Ücretli adımlar:** video üretimi (Omni/Veo/Kling vb. modeller), seslendirme, montaj — hepsi Higgsfield kredisi.
Onayın olmadan çağrılmaz; bağlantı eklenmedi.
